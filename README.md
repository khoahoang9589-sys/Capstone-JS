# Capstone-JS: Phone-Shop (Website Bán Hàng & Quản Trị)

Dự án Capstone môn JavaScript tại CyberSoft:
- **Trang Bán Hàng (Customer)**: Xem danh mục điện thoại, lọc theo hãng (Apple, Samsung), giỏ hàng mua sắm, lưu trữ LocalStorage.
- **Trang Quản Trị (Admin)**: Quản lý sản phẩm (CRUD RESTful API với Axios), tìm kiếm theo tên, sắp xếp giá, form validation.
- **Kiến trúc**: MVC (Model - View - Controller - Services), Sass 7-1, OOP.
